### Github repository for data analysis - The velvet domain protein regulators control *Verticillium dahliae*'s life cycle through regulation of methyltransferase-encoding genes

## Content: 
1. *data_analyses_thesis.R* contains the statistical analysis and plots for the thesis.
2. *datasets* folder contains the data for the respective analysis.
3. *Figures* folder contains the figures for this thesis.
4. *statistical_results* contains supporting results for the statistical analysis.
5. *preliminary_analysis* folder contains preliminary data, analyses, and figures.
